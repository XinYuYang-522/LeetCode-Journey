# LeetCode 69. x 的平方根

### 1. 一句话核心思路
* **“数值二分（虚拟数组二分）”。** 谁说二分只能在显式数组里用？非负整数 $x$ 的平方根整数部分一定在 `[0, x]` 区间内。在这个天然升序的连续区间内进行二分逼近即可。

### 2. 区间定义与逻辑收缩
* 依然坚持 **左闭右闭区间 `[left, right]`** 策略。
* 核心判断条件为：`mid * mid <= x`。
  * 如果成立：说明 `mid` 是一个潜在的“向下取整”的根，用 `result = mid` 记下，并让 `left = mid + 1` 向右继续试探更大的可能性。
  * 如果不成立：说明 `mid` 太大了，让 `right = mid - 1` 收缩右边界。

### 3. 避坑与大厂八股（整型溢出与除零异常）
* **大坑 1（溢出）：** 当 $x$ 很大时，`mid * mid` 极易超出 `int` 的上限（2147483647）从而在 Java 中溢出变为负数，导致死循环。
  * *解决防线：* 计算乘法时将变量强转提升为 `long`：`(long)mid * mid <= x`。
* **大坑 2（除零）：** 若采用数学流的除法变形 `mid <= x / mid` 来规避溢出，当 $x = 0$ 时会触发第一轮的 `mid = 0`，从而抛出 `ArithmeticException: / by zero`。
  * *解决防线：* 如果用除法，必须在方法开头对 `x == 0` 进行**前置特判**。
