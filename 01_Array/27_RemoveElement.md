# LeetCode 27. 移除元素

### 1. 一句话核心思路
* 使用**快慢指针原地覆盖**：`fast` 负责扫描所有元素，`slow` 指向下一个保留元素应该写入的位置。遇到不等于 `val` 的元素时，将其写入 `nums[slow]`，然后移动 `slow`。

### 2. 循环不变量
* 每轮循环开始时，区间 `[0, slow)` 中保存了已经扫描过的所有非 `val` 元素。
* `fast` 遍历区间 `[0, nums.length)`，确保输入数组中的每个元素都被检查一次。
* 遍历结束后，`slow` 既是下一个可写位置，也是保留元素的数量，因此直接返回 `slow`。

### 3. Java 实现

```java
class Solution {
    /**
     * 原地移除数组中所有等于 val 的元素。
     *
     * 时间复杂度：O(n)
     * 空间复杂度：O(1)
     */
    public int removeElement(int[] nums, int val) {
        int slow = 0;

        // fast 扫描元素，slow 维护有效区间的右边界。
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != val) {
                nums[slow] = nums[fast];
                slow++;
            }
        }

        return slow;
    }
}
```

### 4. 复杂度分析
* **时间复杂度：** $O(n)$。`fast` 从左到右扫描数组一次。
* **空间复杂度：** $O(1)$。只使用 `slow`、`fast` 等常量级变量，并在原数组上完成修改。

### 5. 边界与易错点
* **空数组：** 循环不会执行，返回 `0`。
* **全部等于 `val`：** `slow` 始终为 `0`，返回 `0`。
* **全部不等于 `val`：** 每个元素都会写回原位置，返回原数组长度。
* **不要返回 `slow + 1`：** `slow` 表示有效元素的数量，不是最后一个有效元素的下标。
* **不要处理新长度之后的元素：** 题目只检查 `nums[0, slow)`，后面的内容可以保持不变。

### 6. 面试官考察点
* 是否理解数组无法真正删除中间元素，只能通过覆盖维护有效区间。
* 能否准确说明双指针各自的职责和循环不变量。
* 能否区分“有效长度”和“最后一个有效下标”，并覆盖空数组等边界情况。
