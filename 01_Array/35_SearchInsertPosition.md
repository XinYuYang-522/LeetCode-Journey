# LeetCode 35. 搜索插入位置

### 1. 一句话核心思路
* **带“找不到则插入”功能的二分查找。** 如果在升序数组中找不到 `target`，二分循环结束时，指针指向的位置就是它的完美插入点。

### 2. 区间定义（坚持左闭右闭 `[left, right]`）
* 继承自 704 题的黄金律：
  1. `right = nums.length - 1`
  2. `while (left <= right)`
  3. 分支判断时，`target == nums[mid]` 直接返回；其余情况**必须严格缩紧边界**（使用 `mid - 1` 或 `mid + 1`），严禁使用 `<=` 或 `>=` 造成边界模糊和死循环。

### 3. 避坑与面试重点（为什么最后返回 `left`？）
* **大厂八股必考：** 当 `while(left <= right)` 循环因为 `left > right` 而终止时，必然满足 `left == right + 1`。
* 此时：
  * `right` 刚刚好停在**小于** `target` 的最大元素位置。
  * `left` 刚刚好停在**大于** `target` 的最小元素位置。
* 因此，把 `target` 插入到 `left` 这个索引位置，刚好能让数组继续保持升序。
