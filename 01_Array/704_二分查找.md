# LeetCode 704. 二分查找

### 1. 一句话核心思路
* **有序数组找目标值，直接双指针二分。** 每次通过比较中间值 `mid`，直接砍掉一半不需要搜索的区间。

### 2. 区间定义（我的选择）
* 我选择 **左闭右闭区间 `[left, right]`**。
* **核心连锁反应：**
  1. 既然右边是闭区间，说明 `right = nums.length - 1`（合法下标）。
  2. 循环条件必须是 `while (left <= right)`，因为当 `left == right` 时，`[left, right]` 区间依然有一个数有效。
  3. 没找到时，边界更新为 `right = mid - 1` 或 `left = mid + 1`。

### 3. 避坑与面试重点
* **防止整型溢出：** 计算中间值不能写 `(left + right) / 2`。万一数组极大，两者相加会超过 `int` 最大值导致变成负数。
* **标准写法：** `int mid = left + (right - left) / 2;`
* **我的极客写法：** `int mid = left + ((right - left) >> 1);`
* **注意点：** `>> 1` 优先级极低，外面必须加括号！

### 4. Java 语法备忘
* 获取 Java 数组的长度是一个**属性**，后面**绝对不能加括号**：`nums.length`。
