# LeetCode 367. 有效的完全平方数

### 1. 一句话核心思路
* **“数值二分精确查找”。** 本题是 69 题（x 的平方根）的孪生兄弟。区别在于 69 题是向下取整，而本题是要求**精确匹配**是否存在一个整数 `mid` 满足 `mid * mid == num`。

### 2. 区间定义（坚持左闭右闭 `[left, right]`）
* 在虚拟区间 `[1, num]` 上进行标准二分。
* **核心三段式逻辑：**
  1. 如果 `(long)mid * mid == num`，说明找到了完全平方数，直接 `return true;`。
  2. 如果 `(long)mid * mid > num`，说明当前数太大了，收缩右边界：`right = mid - 1;`。
  3. 如果 `(long)mid * mid < num`，说明当前数太小了，收缩左边界：`left = mid + 1;`。
* 循环结束仍未匹配成功，说明不是完全平方数，返回 `false;`。

### 3. 避坑八股（雷点复盘）
* **强转 `long` 锁死溢出：** 题目中给出的提示 `num <= 2^31 - 1`。当二分到中间时，`mid * mid` 极容易冲破 Java `int` 的天花板。如果漏掉 `(long)` 强转，会导致数据溢出变为负数，逻辑直接彻底溃败。
