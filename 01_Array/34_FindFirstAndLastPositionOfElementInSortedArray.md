# LeetCode 34. 在排序数组中查找元素的第一个和最后一个位置

### 1. 一句话核心思路
* **“边界压迫法”。** 面对含有重复元素的有序数组，不能在找到目标值后使用线性扫描（会导致最坏复杂度退化到 $O(n)$）。应该编写两个纯粹的二分函数，分别向左和向右死磕边界，实现极致的 $O(\log n)$。

### 2. 区间定义（坚持左闭右闭 `[left, right]`）
* 核心破局点：当 `nums[mid] == target` 时：
  * **找左边界 (`findFirst`)**：即便找到了相等的值，依然不停下，记录当前位置后令 `right = mid - 1`，强行把搜索区间向左推。
  * **找右边界 (`findLast`)**：同理，记录当前位置后令 `left = mid + 1`，强行把搜索区间向右推。

### 3. 避坑与面试高频八股
* **面试官追问：代码重复，能否合并为一个函数？**
  * **研究生高分回答：** 可以通过传入一个 `boolean` 标志位（如 `isLeft`）在同一个二分中进行逻辑判断。但在工业界实践和面试手写代码中，**更推荐拆开写**。拆开写符合**单一职责原则**，逻辑极其清爽高内聚，能有效避免在复杂的边界控制（如 `left = mid` 导致的死循环）中翻车，可读性和可维护性更高。
